# Glossaire final

<div class="encadre astuce">
<span class="encadre-titre">💡 Note sur cette annexe</span>
Chaque terme est défini simplement, comme il l'a été introduit dans le corps du manuel — avec un renvoi au chapitre où l'explication complète (analogie comprise) se trouve.
</div>

| Terme | Définition simple | Chapitre |
|---|---|---|
| **CMD** | Le shell historique de Windows, hérité de MS-DOS, maintenu pour compatibilité. | 2 |
| **PowerShell** | Le shell moderne de Windows, manipulant des objets plutôt que du texte. | 2, 9 |
| **Cmdlet** | Une commande PowerShell native, nommée selon la convention Verbe-Nom. | 9 |
| **Pipeline** | Le mécanisme (`\|`) qui transmet le résultat d'une commande à la suivante. | 9, 12 |
| **Objet** | Une structure de données avec des propriétés (données) et des méthodes (actions). | 12 |
| **Propriété** | Une donnée consultable d'un objet, lue sans parenthèses. | 12 |
| **Méthode** | Une action exécutable d'un objet, appelée avec des parenthèses. | 12 |
| **Variable** | Un nom (`$x`) désignant une valeur stockée en mémoire. | 13 |
| **Script** | Un fichier contenant une suite d'instructions, exécutable en une fois. | 8, 16 |
| **Module** | Un ensemble de fonctions PowerShell réutilisables, regroupées dans un fichier `.psm1`. | 24 |
| **API** | Une interface permettant à des programmes de communiquer entre eux via des requêtes structurées. | 21 |
| **JSON** | Un format de texte structuré, très utilisé pour la configuration et les échanges de données. | 3, 21 |
| **DNS** | Le service qui traduit un nom de domaine (google.com) en adresse IP. | 20 |
| **IP** | L'adresse numérique unique d'un appareil sur un réseau. | 1, 20 |
| **TCP** | Un protocole de transport réseau fiable, utilisé par la plupart des services (HTTP, SSH...). | 20 |
| **UDP** | Un protocole de transport réseau plus rapide mais sans garantie de livraison. | 20 |
| **Port** | Un numéro identifiant un service précis sur une machine réseau (443 pour HTTPS, par exemple). | 20 |
| **Service** | Un processus Windows sans fenêtre, tournant en arrière-plan en continu. | 1, 18 |
| **Processus** | Un programme en cours d'exécution, avec un identifiant unique (PID). | 1, 17 |
| **WinRM** | Le protocole de transport utilisé par PowerShell Remoting pour administrer une machine à distance. | 25 |
| **UAC** | Le mécanisme Windows qui confirme toute élévation de privilèges administrateur. | 22 |
| **ACL** | La liste de contrôle d'accès associée à un fichier ou dossier NTFS. | 22 |
| **Azure** | Le service Cloud de Microsoft, administrable en PowerShell via le module `Az`. | 26 |
| **Docker** | Un outil de conteneurisation, permettant d'empaqueter une application avec son environnement. | 27 |
| **Git** | Un système de gestion de versions, utilisé pour suivre l'historique du code source. | 27 |
| **CI/CD** | *Intégration continue / Déploiement continu* — l'automatisation des vérifications et déploiements de code. | 28 |
| **Cloud** | Un modèle de location de puissance de calcul/stockage à l'usage, plutôt que de matériel possédé. | 26 |
