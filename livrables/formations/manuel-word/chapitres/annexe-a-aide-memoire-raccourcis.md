# Aide-mémoire général des raccourcis clavier

Cette annexe rassemble, par thème, l'intégralité des raccourcis clavier enseignés dans ce manuel, avec le chapitre où chacun a été introduit en détail. Elle est conçue pour une consultation rapide, pas pour une lecture linéaire.

<div class="encadre attention">
<span class="encadre-titre">⚠️ Une précision sur les claviers localisés</span>
Les raccourcis de ce manuel correspondent à une installation de Word en français avec un clavier AZERTY. Certaines lettres associées à un raccourci suivent la logique française plutôt qu'anglaise — par exemple, **Gras** est `Ctrl+G` (et non `Ctrl+B` comme en anglais), tandis que la boîte de dialogue **Atteindre** utilise justement `Ctrl+B` en français (et non `Ctrl+G` comme en anglais) — une inversion entre les deux langues qui surprend souvent qui a appris Word sur un poste anglophone.
</div>

## Gestion des documents (chapitre 5)

| Raccourci | Action |
|---|---|
| `Ctrl+N` | Nouveau document vierge |
| `Ctrl+S` | Enregistrer |
| `F12` | Enregistrer sous |
| `Ctrl+W` | Fermer le document actif |
| `Alt+F4` | Fermer Word entièrement |

## Navigation (chapitre 6)

| Raccourci | Action |
|---|---|
| `Ctrl+Début` | Aller au tout début du document |
| `Ctrl+Fin` | Aller à la toute fin du document |
| `Ctrl+flèche gauche/droite` | Déplacement mot par mot |
| `Ctrl+flèche haut/bas` | Déplacement paragraphe par paragraphe |
| `Ctrl+F` | Rechercher (volet de navigation) |
| `Ctrl+B` ou `F5` | Atteindre (page, signet, tableau, note...) |
| `Ctrl+Maj+8` | Afficher/masquer les marques de mise en forme |

## Sélection, presse-papiers et édition (chapitre 7)

| Raccourci | Action |
|---|---|
| `Ctrl+A` | Tout sélectionner |
| `Ctrl+C` | Copier |
| `Ctrl+X` | Couper |
| `Ctrl+V` | Coller |
| `Ctrl+Maj+V` | Coller sans mise en forme |
| `Ctrl+H` | Rechercher et remplacer |
| `Ctrl+glisser` (souris) | Copier par glisser-déposer |
| `Ctrl+Z` | Annuler la dernière action |
| `Ctrl+Y` | Rétablir l'action annulée |

## Mise en forme de caractères (chapitre 9)

| Raccourci | Action |
|---|---|
| `Ctrl+G` | Gras |
| `Ctrl+I` | Italique |
| `Ctrl+U` | Souligné |
| `Ctrl+D` | Boîte de dialogue Police complète |
| `Ctrl+Maj+=` | Exposant |
| `Ctrl+=` | Indice |
| `Ctrl+Maj+C` | Copier la mise en forme (Pinceau clavier) |
| `Ctrl+Maj+V` | Coller la mise en forme copiée |
| `Ctrl+Barre d'espace` | Effacer la mise en forme de caractère |

## Mise en forme de paragraphes (chapitre 10)

| Raccourci | Action |
|---|---|
| `Ctrl+L` | Aligner à gauche |
| `Ctrl+E` | Centrer |
| `Ctrl+R` | Aligner à droite |
| `Ctrl+J` | Justifier |

## Mise en page et sections (chapitres 15-16)

| Raccourci | Action |
|---|---|
| `Ctrl+Entrée` | Saut de page manuel |
| `Ctrl+Maj+Entrée` | Saut de colonne manuel |

## Documents longs, champs et références (chapitres 27-35)

| Raccourci | Action |
|---|---|
| `F9` | Actualiser le champ, la formule ou la table sélectionnée |
| `Ctrl+A` puis `F9` | Actualiser tous les champs du document |
| `Alt+F9` | Basculer entre le résultat et le code brut d'un champ |
| `Ctrl+Maj+F9` | Convertir un champ en texte statique définitif |
| `Ctrl+Alt+F` | Insérer une note de bas de page |
| `Ctrl+Alt+D` | Insérer une note de fin |
| `Alt+Maj+X` | Marquer une entrée d'index |
| `Ctrl+K` | Insérer un lien hypertexte |
| `Ctrl+clic` | Suivre un lien hypertexte ou un renvoi |

## Documents structurés (chapitre 33)

| Raccourci | Action |
|---|---|
| `Alt+Maj+flèche gauche` | Promouvoir un titre d'un niveau (mode Page ou Plan) |
| `Alt+Maj+flèche droite` | Rétrograder un titre d'un niveau (mode Page ou Plan) |

## Macros et VBA (chapitres 36-37)

| Raccourci | Action |
|---|---|
| `Alt+F8` | Ouvrir la boîte de dialogue Macros |
| `Alt+F11` | Ouvrir/fermer l'éditeur Visual Basic |
| `F5` (dans l'éditeur VBA) | Exécuter la macro |
| `F8` (dans l'éditeur VBA) | Exécuter pas à pas, pour déboguer |

## Collaboration et révision (chapitres 38-39)

| Raccourci | Action |
|---|---|
| `Ctrl+Maj+E` | Activer/désactiver le suivi des modifications |
| `Ctrl+Alt+M` | Ajouter un nouveau commentaire |

## Impression (chapitre 44)

| Raccourci | Action |
|---|---|
| `Ctrl+P` | Ouvrir l'écran d'impression et son aperçu |
